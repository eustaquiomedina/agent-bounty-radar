Agent Bounty Radar

Search "AI agent bounties" and you get a dozen platforms promising real money for real agents. We actually checked what each one's own live data says — API responses, GitHub issue status, working buttons — instead of trusting the homepage copy. About half of what we checked doesn't hold up.

Last verified: 2026-08-31. This list gets rechecked, not just added to — a "real" today can go stale tomorrow.

Method

For a marketplace, we check its own numbers against reality: does the documented API actually respond, do "open" issues still show open on GitHub itself, do the buttons navigate anywhere. For a hackathon or grant, we read the full page, not the headline, and check the deadline against today's date. No platform on this list paid to be here, and none of it is affiliate-linked.

Real — functioning, real transactions/data Real but thin — works, but very little actual volume/demand Not functioning — demo/mockup or broken Pivoted away — used to do this, doesn't anymore
General-purpose AI agent / bounty marketplaces
PlatformClaimsStatusWhat we actually found
Taskmarket Escrow marketplace, USDC payouts on Base Real Functioning agent/wallet CLI, real open tasks, real escrow flow. We have a live agent on it with several prepared submissions. Reward sizes are small (fractions of a USDC to ~25 USDC).
Superteam Earn (Agent API) Bounty feed for agents Real API works and returns real listings, but at check time nothing fresh with a future deadline and unannounced winner. Worth a recurring check, not a one-time one.
BountyBook Python/code bounties, USDC Real Public API returns real open jobs. Submitting requires EVM wallet-signature auth, not just an account — plan for that before you build a solution.
Boss.dev Bounties on real GitHub issues Real, gated Alpha product. The actual bounty list is behind "Log in with GitHub" OAuth — you can't see what's available without authorizing the app first.
IssueHunt Funded GitHub issues Real, stale data The platform is real, but its "funded" list isn't reconciled against GitHub — several issues shown as open/funded were already closed with a merged PR weeks earlier. Check the exact issue number on GitHub itself before reading further.
Opire OSS bounties, $70–$3,280 seen Real, stale data Same problem as IssueHunt, worse: of 4 low-competition candidates we checked in detail, all 4 had the issue already closed or the repo didn't exist at all. Big real repos (Godot, TypeORM, Zed) have real, proportional competition; several small $100-200 listings show spam/farming patterns.
Algora OSS bounty board Pivoted Now an engineer-recruiting product ("Hire the top 1% open source engineers"). No public open-bounty board anymore; orgs that used to list bounties show zero open today.
Polar.sh Fund a GitHub issue Pivoted Now positions itself as a SaaS billing platform. No public directory of funded issues anymore.
x402 / on-chain agent-payment marketplaces
PlatformClaimsStatusWhat we actually found
402bazaar.com x402 service marketplace, Base/USDC Real, empty Real, working x402 registration flow (0.10 USDC to list). Its own public stats: 1 service listed, 9 transactions in its entire history, 9 USDC moved total. Too empty to be a channel yet, useful as a technical reference.
agentbounties.app "Pay for verifiable results," Base/USDC Self-funding scheme Live and technically working, but almost every listed "opportunity" requires you to create and fund a child bounty with your own money to win a slightly larger reward from the platform's own liquidity ranking — that's staking your own capital, not getting paid for outside demand. Lifetime volume: ~66 USDC across 52 "completed" bounties.
DoraHacks — x402 Agent Marketplace $50,000 prize hackathon Real, closed Genuinely real $50k pool, but that edition's submission window ended in February 2026. Worth watching for the next edition, not actionable today.
Newer "agents doing gig work" marketplaces
PlatformClaimsStatusWhat we actually found
BotBounty.ai No-signup bounty API, paid in ETH on Base Down at check time The best-designed of the bunch on paper: no OAuth, wallet-address-only identity, documented REST API. But its documented endpoint (GET /api/agent/bounties) returned a server error twice in a row when we called it. Worth rechecking — a young, possibly just-fragile deployment, not obviously fake.
agentbounty.org "$83,400 in active bounties" Not functioning All 12 listed "active" bounties have deadlines from February–March 2026 — already months in the past. "View Details" buttons don't navigate anywhere. The listed sponsor companies don't resolve to any real, findable organization. This reads as a static demo/mockup, not a live marketplace.
trybounty.ai "Trusted by 10,000+ early users" No agent-side flow, zero live data Live counters on its own homepage read 0 tasks completed, 0 active agents, $0.00 verified earnings — directly under a row of customer testimonials describing completed work. No visible way for an agent to browse or claim a bounty as a solver; the entire public flow is "post a bounty" as a buyer.
