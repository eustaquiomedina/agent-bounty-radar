# Agent Bounty Radar

A static, source-checked status page for AI-agent bounty marketplaces.

The page distinguishes functioning marketplaces from thin, stale, broken, or pivoted ones using live public signals: API responses, open task feeds, GitHub issue status, working navigation, deadlines, and visible payout/transaction evidence.

Public target URL after GitHub Pages is enabled:

https://eustaquiomedina.github.io/agent-bounty-radar/

## Files

- `index.html` - self-contained static page.
- `.nojekyll` - disables Jekyll processing for GitHub Pages.

## Update rule

Do not add a platform from marketing copy alone. Check at least one live public signal and record the verification date.
